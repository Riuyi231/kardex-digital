Sistema y respaldos

            
Respaldo de la base de datos, importación de empleados y documentos internos.

          

        


        

          
💾 Respaldo de la base de datos

          
Cree copias de seguridad de toda la información (empleados, nómina, correos, configuraciones). Cada respaldo se guarda localmente y, si configura una carpeta adicional, también se copia a la nube o red.

          

            
            
            
          

          

            
            
            
          

          
Apunte a una carpeta sincronizada con la nube (OneDrive, Google Drive) o a una carpeta de red en otra computadora, para que un fallo del disco del servidor no pierda los respaldos. Deje vacío para guardar solo en la carpeta local.

          

            
            
          

          

        


        

          
📥 Importar empleados desde Excel

          
Descargue la plantilla, complétela y súbala. Las columnas que no reconozca se omiten; las cédulas o correos duplicados se reportan sin importarse.

          

            
            
            
          

          

        


        

          
🧹 Reiniciar historial de salarios

          
Útil cuando se cargaron salarios de prueba. Esto borra los cambios de salario registrados y deja como base el salario actual de cada empleado activo desde el 1 de enero del año, para que la regalía use solo los salarios reales. El módulo de cambios de salario sigue funcionando para cambios futuros. Ejecútelo después de cargar los salarios definitivos.

Conexión y servidor

        
      

      

        
Elige cómo se usarán los datos de KARDEX en esta PC.

        

          
          
        


        

          
Esta PC usa la base de datos local de este equipo (archivo kardex.db). Los datos no se comparten por red ni por Internet.

        


        

          
Esta PC usará la base central y el OCR del servidor de Internet (ej. un VPS con https://kardexdigital.duckdns.org). No necesita ser servidor ni estar en la misma red.

          
          
          

            
            
          

          


          
          
          
          
          
          

          
Al conectar, KARDEX guarda las credenciales, se conecta a la nube y reinicia la app.
