KARDEX Digital · Sistema de Licencias

Guía para el vendedor y el usuario final · Versión 1.0

1. Cómo funciona

Cada instalación de KARDEX Digital funciona durante 15 días de prueba gratuita (empieza automáticamente en la primera ejecución). Para seguir usándolo hay que activar una licencia. La licencia es una clave firmada digitalmente: no se puede fabricar ni modificar sin la llave privada del vendedor.

Tipos de licencia
  • pyme — para un solo equipo (sin servidor).
  • red — para empresas con servidor y varios puestos.
Vigencia — por días (ej. 365) o perpetua (0 días = nunca vence).
Vinculación — una licencia puede usarse en cualquier PC o quedar atada a una computadora específica (por su ID de máquina).

2. ¿Qué es el ID de máquina?

Es un código de 32 caracteres (ej. F24AA38A2A68C7759ECFB7A4DCFC7959) que identifica a cada computadora. Se ve en la ventana de activación (Licencia → Activar licencia). Se calcula del nombre del equipo, usuario y GUID de Windows; no se puede "copiar" de una PC a otra.

3. Activar una licencia (usuario final)

  1. Abrir KARDEX Digital y hacer clic en Licencia (debajo de la contraseña en el login).
  2. Pegar la clave en el cuadro o pulsar Cargar archivo .lic.
  3. Pulsar Activar. La clave queda guardada en kardex-license.json junto a la base de datos.

4. Emitir licencias (solo el vendedor)

Método fácil (recomendado): usa el programa KeyForge (instalador KeyForge-Setup.exe), un generador de licencias genérico que sirve para KARDEX y para cualquier otro programa que fabriques. Es solo para tu uso: seleccionas la llave privada la primera vez, llenas los datos y pulsa Generar licencia. Te deja copiar la clave o guardar el archivo .lic.
IMPORTANTE: la carpeta keys\ con vendor-private.pem es la llave maestra. No compartirla ni incluirla en el instalador. Si se pierde, no se pueden emitir más licencias sin reconstruir la app.

Alternativa por consola o doble clic: Generar-Licencia.bat te pregunta todo paso a paso y deja la licencia en Licencias\. Ver-ID-mi-PC.bat muestra el ID de una computadora.

Si prefieres la línea de comandos:

node scripts/make-license.js --company "EMPRESA S.A." --type red --seats 8 --days 365

Esa licencia sirve para cualquier PC (tipo red). Para atarla a una PC concreta:

node scripts/make-license.js --company "CLIENTE" --type pyme --seats 1 --days 365 --machine "F24AA38A2A68C7759ECFB7A4DCFC7959"

Para generarla atada a la PC donde se corre el comando: usar --machine-this.

Para guardar la clave en un archivo listo para enviar: agregar --out "ruta\LICENCIA.lic". El cliente lo carga con Cargar archivo .lic.

Nota: la primera vez que se emite una licencia hay que generar el par de llaves con node scripts/make-license-keys.js. Esto crea keys\vendor-private.pem y services\license-pub.js. La llave pública queda embebida en el instalador.

5. Reemisión y renovación

  • Renovar: emitir una nueva licencia con más días para la misma empresa/máquina; el cliente la activa y sobreescribe la anterior.
  • Cambio de PC: si la licencia estaba atada a una máquina, se emite una nueva con el ID de la nueva computadora (el cliente lo lee en la ventana de licencia).
  • Restaurar sistema: al instalar Windows de nuevo cambia el ID de máquina; se debe reemitir la licencia con el ID nuevo.

6. Resolución de problemas

MensajeSolución
«Licencia no disponible…» al iniciar sesión o como servidorLa prueba venció y no hay licencia activa. Activar una licencia o renovar la prueba.
«La licencia no corresponde a esta computadora»La licencia está atada a otro equipo. Verificar el ID de máquina y pedir una licencia nueva.
«La licencia está vencida»Emitir/activar una licencia renovada.
«El archivo de licencia no es válido»El archivo está dañado o fue modificado. Reenviar la clave original.
La clave no se pega o se ve en blancoCopiar la clave completa desde la línea «CLAVE DE LICENCIA» (sin espacios ni saltos).
